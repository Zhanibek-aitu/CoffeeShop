# ☕ Aroma Blend Coffee - Assignment #2 (Advanced CSS: Flexbox & Grid)

Multi-page specialty coffeehouse website created for the **Web Technologies 1** course at Astana IT University (AITU).

🌐 **Live Website:** [View Live Site](https://zhanibek-aitu.github.io/CoffeeShop/)

## ✨ Key Layout Implementations (Assignment 2)
- **Flexbox Navigation:** Modern responsive header with logo and links (`justify-content: space-between`, `align-items: center`).
- **Flexbox Card Row:** Equal-height signature roast cards with smooth hover lift and shadow effects.
- **CSS Grid Areas Layout:** Complete `blog.html` page structured with named grid areas (`header`, `sidebar`, `content`, `footer`).
- **Image Gallery (3x3 Grid):** 9 curated high-resolution specialty coffee images featuring hover overlay caption effects.
