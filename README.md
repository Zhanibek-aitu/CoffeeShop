# ☕ Aroma Blend Coffee - Assignment #4 (Introduction to JavaScript)

Interactive specialty coffeehouse web application built for the **Web Technologies 1** course at Astana IT University (AITU).

🌐 **Live Website:** [View Live Site](https://zhanibek-aitu.github.io/CoffeeShop/)

## ⚡ Interactive JavaScript Features (Assignment 4)
- **Client-Side Form Validation:** Dynamic input checking on `contact.html` (required fields, email regex verification, password length $\ge 6$ chars, and password confirmation matching with inline error feedback).
- **FAQ Accordion:** Interactive collapsible questions and answers with smooth toggle and dynamic `+` / `−` icon states.
- **Modal Popup Window:** Promotional subscription pop-up with dark overlay, dismissible via close button or by clicking outside the modal area.
- **Dynamic Theme Switcher:** Button cycling through warm coffee background colors using JavaScript DOM style manipulation and modulo logic.
- **Live Clock & Date Display:** Formatted date and time (e.g., *"October 9, 2026, 10:45:12 AM"*) updating every second via the `Date` object and `setInterval`.
